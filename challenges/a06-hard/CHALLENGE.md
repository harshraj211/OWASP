# A06:2025 - Insecure Design (Hard)

## Coupon and Wallet Abuse

Apex Sovereign Vault is a members-only private asset repository. The catalog features an ultra-rare **Obsidian Sovereign Key**, but purchasing it requires Sovereign VIP tier status, an enormous wallet balance (₹50,000.00), and signed transaction verification.

Chain multiple business-logic and architectural design flaws to bypass coupon restrictions, escalate your membership tier, forge transaction authorization tokens, and acquire the restricted Obsidian Sovereign Key.

- Category: A06:2025 - Insecure Design
- Difficulty: Hard
- Estimated time: 35-60 minutes
- Flag format: `CTF{...}`
- Starting balance: `₹50.00`

Only interact with the challenge through its web interface and HTTP requests.
