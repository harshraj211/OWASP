Cryptographic Consensus Specification

Titan Defense operates a strict SHA-256 cryptographic chain. Each block header links directly to its ancestor:

hash = sha256(index | prev_hash | timestamp | event_type | details)

Integrity Policy: Redacting historical records breaks all downstream hashes. Administrators modifying records must recalculate downstream block linkages to preserve consensus before vault lockouts can be cleared.

API Enabled

Automated programmatic updates can be performed via POST /api/v1/audit/tamper-block using JSON payloads.
